# Online Bookstore – DevOps CI/CD Project

## Project Overview

This project demonstrates deploying a Java web application using a CI/CD pipeline.

**Application source:** Existing open-source Java web application  
**DevOps implementation:** Ganesh

## Technologies Used

- AWS EC2
- Linux
- Git & GitHub
- Jenkins
- Maven
- Apache Tomcat

## CI/CD Pipeline

GitHub → Jenkins → Maven → WAR → Tomcat → AWS EC2

## My DevOps Work

- Configured Jenkins on AWS EC2
- Integrated GitHub with Jenkins
- Configured Maven build
- Generated WAR file
- Deployed WAR file to Apache Tomcat
- Hosted the application on AWS EC2

## Jenkins Build

Jenkins was used to pull the source code from GitHub and build the application using Maven.

## Tomcat Deployment

The generated WAR file was deployed to Apache Tomcat running on AWS EC2.
